# HR Analytics Dashboard – Employee Workforce Analysis

## Project Overview

This project focuses on Human Resource (HR) Analytics, using data visualisation to provide meaningful insights into employee demographics, workforce distribution, promotion eligibility, employee retention, and other important HR metrics.

The dashboard provides an interactive visual representation of workforce information, helping HR professionals and management understand employee distribution and make informed, data-driven decisions.

## Project Objectives

The major objectives of this project are to:

- Analyse employee demographics and gender distribution.
- Identify employees due and not due for promotion.
- Examine employee retrenchment status.
- Monitor active workforce distribution.
- Analyse employee years of service.
- Evaluate employee distribution across different job levels.
- Examine employees' distance from the office.

## Tools and Technologies

- Microsoft Excel – Data handling and preparation.
- Microsoft Power BI – Data visualisation and dashboard development.
- Power Query – Data transformation and cleaning.

## Dashboard Highlights

The dashboard presents the following key performance indicators (KPIs):

1. Total Employees
2. Male and Female Employee Distribution
3. Employees Due for Promotion
4. Employees Not Due for Promotion
5. Employees Next for Retrenchment
6. Active Workers
7. Years of Service Analysis
8. Job Levels Distribution
9. Distance from Office Analysis
